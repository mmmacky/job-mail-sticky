# 求职便利贴 0.2
本地 Windows 笔试与测评邮件待办。每封邮件独立处理，不合并，不接入 LLM。

## 使用
解压安装包，打开 Setup.exe，分别选择程序与数据目录，可选择 E 盘。
安装器可创建桌面及登录启动快捷方式。第一次运行在 QQ 邮箱设置中开启 IMAP，使用授权码测试连接成功后保存。
目前只支持 QQ / Foxmail。新安装不含任何账号、真实邮件或个人链接。
安装包未进行数字签名；其他 Windows 版本和杀毒软件环境尚待验证。

## 功能
- 每封邮件单独列出。双击查看正文文字版、可点击链接，并可导出完整原始 .eml 文件。
- 支持手动事项：名称、开考/截止时间、链接、备注；保存按钮固定在底部。
- 主窗口与详情窗口不强制置顶，点击哪个就切换到哪个。
- 关闭主窗口收起到托盘，左键打开、右键退出；登录后打开并更新，无 Windows 主动提醒通知。
- 首次扫描近90天收件箱，之后按IMAP UID增量读取；断网自动重试，唤醒后补同步。
- 同步进度与事项一起保存，失败不推进；移除和完成状态保留。
- 区分开考、最晚进入、结束及测评截止，支持相对小时、日历天、下午时间、跨年、闰年与明示UTC偏移。
- 5个自然日等边界不明确的表述，显示计算假设和待核对标记。
- 数据目录可更换，提供退出账号、清除缓存、导出脱敏诊断。

## 数据与隐私
源码版优先使用已有 data 文件夹；否则使用本机 LocalAppData/JobMailSticky。
安装版在 data-location.json 指向的独立目录保存数据。
邮箱授权码由 Windows DPAPI 加密，只适用于同一Windows用户；缓存及原始邮件是明文，含个人链接。
原始邮件可能包含附件。迁移数据保留旧目录副本，清除当前缓存不会清理旧副本。
导出诊断不包含邮件正文、账号、链接或本机路径。
公开项目时不要上传 data、originals、data-location.json、配置、日志或真实邮件截图。
程序不发信，不删除邮箱邮件，不改变已读状态。

## 限制
只扫描收件箱，附件内容不参与时间识别。正文以文字版显示，不加载远程图片或运行邮件脚本。
工作日节假日、首次操作起算、复杂多场考试等仍可能需要手动核对。
Windows本地时区用于未注明时区的事件；相对小时从邮件Date头起算，“收到”以发送时间代算。
电脑关机/睡眠期间不运行。退出程序后停止同步。
移动安装目录后请重新创建快捷方式或运行安装器；独立数据目录应保持可访问。
安装器为 ZIP 内的独立 Setup.exe 及支持库，不需要系统安装 Python。

## 开发
Windows + Python 3.9或更新版本（建议使用受支持版本）。
安装 requirements.txt 后运行 python sticky.py。
运行测试：python -m unittest discover -s tests -v。
模块：sticky.py 界面；mail_sync.py 收信；schedule_parser.py 时间规则；mail_content.py 正文；
runtime_support.py 托盘与数据目录；installer.py 安装器。
安装包在当前 Windows 系统完成启动和独立目录测试；尚未做多机验证。
